The base is an ancestor of current Admin. Current Admin contains **103 additional commits** and **33 first-parent commits** in this range. Each commit below was read against its first parent. A merge row lists its own delta in context with the topic changes it integrated.

The source comparison uses New Admin candidate `68c318a7437701314e4b779163e0183cb4c84398`. The **Current paths** column counts files from the commit's delta with a surviving change from the base to current Admin, then counts how many of those paths differ in the candidate. A source match confirms the candidate carries that file state. The action evidence is recorded separately.

- Both `supabase/` and `mobile/supabase/` serve the shared system. A mobile task with a shared server or web client dependency is identified in its row.
- Hosted release evidence includes read-only verification. Synthetic signed-in tests exercise saves, send queues and role or tenant boundaries.
