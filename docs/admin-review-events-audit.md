## Outstanding specialist operations

- The new Draw generator, group edits and exact review, schedule publication, result entry, native live/featured toggles, draw reopen, and announcement publish/remove are browser-tested against synthetic data. The branch adds reviewed bulk and individual match setup in `3b445826`. The separate ad hoc play dates and direct per-division court plan saves remain open. The relevant source is `NativeDrawManager.jsx` at the functions `saveMatchOperations`, `removePlayDay`, `applyBulkMatchSetup` and `saveDivisionSchedulePlan`. The original Tournament schedule path serves the separately verified aggregate `tm_save_schedule` and `tm_publish_schedule` workflow.
- The branch now has exact native draw completion and reviewed ranking awards in `56b95d4`. Synthetic Chrome covers completion for one draw, an atomic ranking insert excluding existing awards, and rejection of a stale fixture or points review. The shared generator includes Top 8 placement. Separate linked Silver and Bronze plates still depend on a server operation that can create the draw, fixtures and routing consistently.
- The legacy Calendar operations can use fuzzy names to match imported events. New Admin uses exact source IDs or canonical provider links and flags ambiguous or locally hosted matches for manual review. It preserves existing records as a deliberate data-protection decision.
- A new draw requires the current player list, format and applicable seeding confirmations. AAA Eastern Cape Open had two active divisions and no saved draws per the lead's read-only check. The explicit entry route, division selection and exact `tm_save_draw` payload were exercised against synthetic data. Real AAA preparation state and writes were not exercised.
