# Event draw sources

An event can accept registrations in 4M (`is_manual: true`) while publishing its draw in RankedIn. Registration mode must not choose the draw source.

The app follows the website's public draw route: a valid RankedIn tournament ID (or tournament URL) selects RankedIn; otherwise a manual event selects native draws. Explicit native division/match notification links still select the native draw for a hybrid event.

Draw availability reads the shared `rankedin_results_cache` and newer populated classes from `rankedin_cache`. Opening a draw page refreshes the canonical classes cache. `sync_rankedin_draw_status` propagates that publication flag to the summary cache without an additional provider request and without marking winners/results as freshly synced. Empty payloads preserve known publication; populated unpublished classes can withdraw a draw. Older classes cannot overwrite a newer summary.

The app's Draws and Results tabs render React Native controls and match cards, using the existing app session. There is no website/browser handoff. Published divisions, knockout rounds, placement playoffs and round-robin standings are available inside the tournament. Approved player portraits and country flags appear where available; missing portraits use initials. Scores preserve individual sets or an explicitly labelled match total. South African match times always display in SAST.

Every match card also displays its round title. RankedIn third-place playoffs retain the explicit `3rd place playoff` title instead of the generic `Playoff`. Native matches sharing a round number are split by their published round labels, so a final and its third-place playoff cannot appear together under `Final`. The completed Growthpoint age-group fixtures verify one championship final per division: Ockie Oosthuizen/Scott Whysall (Men 35+) and Paul Atkinson/Paul Waldburger (Men 45+). Martin Redelinghuys/James Munro and Brad Vermeulen/Brandon Weir-Smith won the respective third-place playoffs. These display changes require an updated app build.

Website draw links opened inside the app route to the native event tab. `/native-draws/:slug` preserves an explicit native source for hybrid tournaments, including division/match notification targets. Native published draws use the same RLS-protected draw tables as the website, and Results retains the player's points awards. An unrelated player/organisation query failure cannot hide a successfully loaded published draw.

RankedIn reads use the canonical `rankedin_cache` keys consumed by the website. A fresh snapshot is served without a provider call. The `tournament-draws` Edge Function authenticates the existing app access token, validates a visible approved event and its published division/stage, and refreshes stale/missing snapshots server-side. Service-only atomic leases limit each URL to one refresh every two minutes, with a shared ceiling of 30 refreshes per minute. Empty provider responses and failures preserve a populated snapshot. The app never fetches RankedIn draw URLs directly. Foreground refreshes preserve the selected division/round and show the last-available timestamp when the cache is stale.

RankedIn knockout bracket participant order can differ from the underlying challenge's score order. Resolve the displayed winner from `WinnerParticipantId` before using `IsFirstParticipantWinner`. If that participant ID names the opposite bracket side from the score's winner flag, reverse every set and any summary total when normalizing the snapshot. Do not mutate the shared cache.
